<h3 align="center">Runesgalder</h3>

<p align="center">A governed runtime for agent workflows and safe C# code execution.</p>

<p align="center">Two surfaces over one runtime: Flow, typed agent orchestration, and Sandbox, a deny-by-default execution boundary for untrusted AI-generated C#.</p>

<p align="center"><strong>Pre-alpha.</strong> Not production ready. No packages have been published.</p>
